# ImageCare

[English](README.md)

ImageCare — настольное приложение для быстрого просмотра, сортировки, разметки и перемещения больших коллекций фотографий в Windows и macOS.

Например, бердвотчер вернулся с полевой съёмки с флешкой на 6000 изображений. В ImageCare он может просмотреть съёмку на временной шкале, оценить удачные кадры, добавить теги и разложить выбранные файлы по папкам.

<img src="docs/images/image_care_screenshot.png" width="800" alt="Главное окно ImageCare" />

## Возможности

- Две панели папок и общая лента превью для сортировки файлов между каталогами.
- Обзор папки с временной шкалой, настраиваемой сеткой, сортировкой и списком удалённых файлов.
- Кластеризация по времени съёмки отмечает связанные серии кадров цветными рамками в папках, содержащих до 5000 медиафайлов.
- Извлечение превью и поиск по метаданным JPEG, RAW-изображений (включая DNG) и видео MP4.
- Карта места съёмки выбранного Canon CR3, Sony ARW, Nikon NEF или DNG с GPS-координатами, маркером и копированием координат.
- Рейтинги и теги в сопутствующих файлах XMP.
- Словари тегов можно загружать из текстовых файлов UTF-8; `tags-example.txt` содержит алфавитный список 325 видов птиц Беларуси.
- Индексированный поиск по свойствам файла, рейтингу и тегам.
- Настраиваемые операции копирования, перемещения, удаления, перетаскивания и открытия во внешних приложениях.
- Буфер безопасного удаления с восстановлением файлов.
- Русский и английский интерфейс.

## Карта места съёмки

Если EXIF выбранного изображения Canon CR3, Sony ARW, Nikon NEF или DNG содержит GPS-координаты, в основном окне просмотра появляется кнопка карты. Она заменяет изображение картой OpenStreetMap, центрирует её на месте съёмки и ставит маркер. Координаты выводятся в формате `широта, долгота`; их можно скопировать в буфер обмена.

Карта показывает только выбранное изображение, а не все файлы папки. ImageCare извлекает GPS-координаты из Canon CR3, Sony ARW, Nikon NEF и DNG. Для загрузки подложки OpenStreetMap нужен интернет.

## Поддерживаемые форматы

| Тип | Форматы |
|---|---|
| Изображения | JPEG/JPG, Canon CR3, Sony ARW, Nikon NEF, Adobe DNG |
| Видео | MP4 |
| Сопутствующие файлы метаданных | XMP |

XMP хранит метаданные и не отображается как отдельный медиафайл.

## Поддерживаемые платформы

Готовые сборки выпускаются для:

- Windows x64;
- macOS arm64 — компьютеров Mac с процессорами Apple.

Linux, Windows x86 и macOS x64 пока не входят в список целевых платформ релизных сборок.

## Установка готовой сборки

Скачайте архив для своей платформы со страницы [GitHub Releases](https://github.com/ondister/ImageCare/releases), распакуйте его и запустите ImageCare. Приложение для macOS подписано локальной подписью. В зависимости от настроек безопасности macOS может запросить подтверждение запуска.

## Сборка из исходного кода

### Требования

- [.NET SDK 10.0.401](https://dotnet.microsoft.com/download/dotnet/10.0) или совместимое обновление 10.0, выбранное через `global.json`;
- macOS или Windows.

### Восстановление зависимостей, сборка и запуск

```bash
dotnet restore ImageCare.sln
dotnet build ImageCare.sln --configuration Release --no-restore
dotnet run --project ImageCare.UI.Avalonia/ImageCare.UI.Avalonia.csproj
```

### Сборка для целевой платформы

macOS arm64:

```bash
zsh scripts/publish-macos-arm64.sh
```

Готовое приложение появится в `artifacts/macos-arm64/ImageCare.app`.

Windows x64:

```powershell
dotnet restore ImageCare.UI.Avalonia/ImageCare.UI.Avalonia.csproj --runtime win-x64 -p:PublishReadyToRun=true
dotnet publish ImageCare.UI.Avalonia/ImageCare.UI.Avalonia.csproj --configuration Release --runtime win-x64 --self-contained true --no-restore -p:PublishReadyToRun=true --output artifacts/windows-x64/publish
```

## Основное управление

| Действие | Управление |
|---|---|
| Копировать выбранный медиафайл | `F5` |
| Переместить выбранный медиафайл | `F6` |
| Удалить выбранный медиафайл | `Delete` |
| Создать папку в панели папок | `F7` |
| Копировать или переместить перетаскиванием | Перетащите превью в другую панель; модификатор и действие по умолчанию задаются в настройках |
| Выбрать активную папку для превью | Выберите каталог в левой или правой панели папок |

Перед обработкой важной коллекции проверьте настройки копирования, перемещения и безопасного удаления на копиях нескольких файлов.
