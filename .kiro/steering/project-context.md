# Контекст проекта ImageCare

## Целевая среда

- Приложение должно одинаково работать в Windows и macOS.
- Любое изменение должно сохранять эквивалентное поведение на обеих платформах.
- При работе с платформозависимым кодом, путями, файловой системой, процессами и интерфейсом учитывай различия Windows и macOS.

## Проверка изменений

- Пользователь тестирует приложение вручную как QA-инженер.
- После изменений запускай приложение и оставляй его доступным для ручного тестирования пользователя.
- Перед запуском выполняй подходящую автоматическую проверку изменённой части, если она предусмотрена проектом.
- Не считай задачу завершённой без запуска приложения. Если запуск невозможен, сообщи причину и укажи команду, которую пользователь может выполнить самостоятельно.
